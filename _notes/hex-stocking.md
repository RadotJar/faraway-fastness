Here follows my current hex stocking procedure. These steps assume you already have laid out general terrain.

As for stocking hexes, my current process uses a mix of pre-rolled hexes and dynamic hexes. It goes something like this.

1. Check each hex for terrain variation using the D30 companion' "Natural Features" table.

2. Check each hex for inhabitation. The D30 companion produces quite high levels of inhabitation, the table in the AD&D 1e DMG produces quite sparse inhabitation. For more detail on each type of feature (ruins, castles etc ) you can use a number of supplements. I’ve enjoyed using the D30 sandbox companion.

3. Add a dungeon in your region

4. You should now have at least a few points of interest to start with. Use these to create a regional wilderness encounter table. I use the 2d6 table structure from Prismatic Wasteland, where 2 is always a dragon. Fill some of the table entries with randomly rolled encounters from your system of choice.

5. Create a regional rumour table using the current points of interest for inspiration and assign it to the nearest town. 

6. Follow [Tenkar's Checklist](https://youtu.be/ZvtpLCcN6FY?si=xGNVsn0xkVQD6pxU) for each hex you have pre-filled to make it interesting. Important that each hex has some connection to at least one other!! 

7. For each encounter on your random encounter table that isnt already associated with a hex, detail a lair. Don't place it yet. If % in lair roll comes up with a lair when you roll the encounter in game, drop your pre-made lair in the current hex. Good to run this dynamic hex against the checklist too
